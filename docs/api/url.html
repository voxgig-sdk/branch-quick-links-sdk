analytics.~secondary_publisher string No secondary publisher specified for the last attributed touch. passed by the ad network.
analytics.~stage string No Use this to categorize the progress or category of a user when the link was generated. For example, if you had an invite system accessible on level 1, level 3 and 5, you could differentiate links generated at each level with this parameter
analytics.~sub_site_name string No Reference to the site where the ad was displayed.
analytics.~tags array of string No This is a free form entry with unlimited values ['string']. Use it to organize your link data with labels that don't fit within the bounds of the above

campaign string No Campaign name
channel string No Deep link channel
data object No

data.$fallback_url string No Change the redirect endpoint for all platforms - so you don't have to enable it by platform. Note that Branch will forward all robots to this URL, which overrides any OG tags entered in the link. System-wide Default URL (set in Link Settings)
data.$fallback_url_xx string No Change the redirect endpoint for all platforms based on a lower-case Alpha-2 country code.
data.$fire_url string No Change the redirect endpoint for Amazon Fire OS Fire default URL (set in Link Settings)
data.$huawei_url string No Redirect to the Huawei App Gallery on Huawei devices. Only link level control. Format should be https://appgallery.huawei.com/app/{HUAWEI_APP_GALLERY_ID_HERE}
data.$ios_url string No Change the redirect endpoint for iOS App Store page for your app (set in Link Settings)
data.$ios_url_xx string No Change the redirect endpoint for iOS based on a lower-case Alpha-2 country code. For example, $ios_url_de="..." would redirect Germany deep link clicks.
data.$ios_wechat_url string No Change the redirect endpoint for WeChat on iOS devices $ios_url value
data.$ipad_url string No Change the redirect endpoint for iPads $ios_url value
data.$marketing_title string No Set the marketing title to see the URL in the Dashboard (must also set type to 2).
data.$mobile_web_only boolean No Force to open the $ios_url, $android_url, or $fallback_url in this order of precedence instead of the app
data.$samsung_url string No Redirect to Samsung Galaxy Store on Samsung devices. Only link level control. Format should be http://www.samsungapps.com/appquery/appDetail.as?appId={PACKAGE_NAME_HERE}
data.$web_only boolean No Force to open the $fallback_url instead of the app
data.$windows_phone_url string No Change the redirect endpoint for Windows OS Windows Phone default URL (set in Link Settings)
duration integer No In seconds. Only set this key if you want to override the match duration for deep link matching. This is the time that Branch allows a click to remain outstanding and be eligible to be matched with a new app session. This is default set to 7200 (2 hours).
feature string No Deep link feature set
qr_code_settings object No QR code customization settings. When included, both the Short Link and its customized QR code are generated instantly. Requires type=2 to be set. This object accepts the same styling parameters as the QR Code API.
qr_code_settings.background_color string No Hex color value of the background of the QR code itself as per https://htmlcolorcodes.com/
qr_code_settings.background_image_url string No URL to an image to be used as the background behind the QR Code.
qr_code_settings.center_logo_url string No URL to the image you want as a center logo for example "https://cdn.branch.io/branch-assets/00000000-og_image.png"
qr_code_settings.code_color string No Hex color value of the QR Code itself as per https://htmlcolorcodes.com/
qr_code_settings.code_pattern enum: 1, 2, 3, 4, 5, 6, ... No QR Code pattern style: 1 = standard, 2 = squares, 3 = circles, 4 = triangles, 5 = diamonds, 6 = hexagons, 7 = octagons
qr_code_settings.code_pattern_url string No Direct link to an image to be used as the code-pattern itself on the QR Code.
qr_code_settings.code_shape integer No Shape of the QR code modules.
qr_code_settings.finder_eye_color string No Hex color value of the finder eye as per https://htmlcolorcodes.com/
qr_code_settings.finder_pattern enum: 1, 2, 3 No The finder pattern shape (top left, top right, and bottom left corners): 1 = square, 2 = rounded rectangle, 3 = circle
qr_code_settings.finder_pattern_color string No Hex color value of the Finder Pattern as per https://htmlcolorcodes.com/
qr_code_settings.image_format enum: png, jpeg, jpg No The output image format that could be either JPEG or PNG
qr_code_settings.margin integer No The number of pixels you want for the margin. Min 1px. Max 20px.
qr_code_settings.width integer No Output size of QR Code image. Min 300px. Max 2000px. (Only applicable to JPEG/PNG)
stage string No
tags array of string No Social media tags
type integer No Set to 2 in order to see Branch Deep Link URLs in the Branch Dashboard (must also set $marketing_title). Note that type=2 is also required to customize a QR code using qr_code_settings.
